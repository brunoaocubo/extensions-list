# Extensions List + Store

Esta é uma simulação front-end de uma lista pessoal de extensões e uma loja de extensões. O objetivo deste projeto é demonstrar a construção do layout responsivo com Mobile First, darkmode de ambas páginas e o fluxo dos dados entre a Extension List e Extension Store utilizando localstorage.

## 📌 Sobre o Projeto
O projeto replica a experiência real do usuário desktop/mobile, persistência de dados local e o gerenciamento de extensões ativas/inativas, tudo executado inteiramente no navegador.

Acesse o site do projeto hospedado no github pages:
https://brunoaocubo.github.io/extensions-list/ <br>


## 🛠️ Funcionalidades

- Remover extensões da lista pessoal.
- Ativar/desativar extensões.
- Adquirir novas extensões da página Extension Store.
- Adicionar as novas extensões na lista pessoal.

--

## 💾 Persistência de Dados

Para garantir o funcionamento offline e sem backend real, foram utilizadas as seguintes estratégias:

* **LocalStorage (Cache):** Utilizado para persistir o estado do usuário, tokens de sessão simulados e cache de preferências, evitando a perda de dados ao atualizar a página.

---

## 🧪 Tecnologias

* **HTML5 / CSS3** (Layout e estilização)
* **JavaScript (ES6+)** (Lógica e manipulação de DOM)
* **LocalStorage API** (Persistência local)
